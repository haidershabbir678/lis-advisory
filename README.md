## 🏛️ Overview

**LIS Advisory** is an elite enterprise consultancy founded on formal **Library & Information Science (LIS / Information Management)** principles. We bridge the gap between archival precision and modern enterprise intelligence—designing high-precision taxonomies, deploying turnkey open-source institutional repositories, and curating zero-hallucination datasets for AI / RAG systems.

---

## ⚡ Core Practice Areas

1. **Enterprise Taxonomy & Semantic Ontology Engineering**
   - Faceted categorization & controlled vocabularies (ANSI/NISO Z39.19 compliant).
   - Machine-readable SKOS & OWL ontology modeling.
   - Cross-system metadata mapping (Dublin Core, MODS, Schema.org).

2. **Turnkey Institutional Repositories & ILS Deployment**
   - Cloud deployment, REST API integration, and customization of **DSpace 8.x** & **Koha ILS**.
   - Legacy catalog migration (MARC21, MARCXML to Dublin Core).
   - OAI-PMH harvesting configuration for global academic indexing (Google Scholar, PubMed).

3. **AI Grounding & RAG Data Curation Suite**
   - High-grade text extraction, semantic chunking, and deduplication of corporate PDF silos.
   - Domain-specific Knowledge Graph schema (Neo4j / RDF).
   - Provenance tracking & citation linking to eliminate LLM hallucinations.

4. **Archival Digitization & Digital Preservation (OAIS)**
   - ISO 14721 (OAIS) standard digital preservation pipelines.
   - Master archival TIFF & PDF/A format conversion.
   - Checksum fixity monitoring (SHA-256) and disaster recovery architectures.

5. **Systematic Literature Reviews & Bibliometric Intelligence**
   - PRISMA-P compliant systematic review search protocols.
   - Bibliometric citation network mapping (VOSviewer, Bibliometrix).
   - Horizon scanning & patent landscape dossiers.

6. **Corporate Records Management & Compliance**
   - ISO 15489-1 business classification schemes & retention schedules.
   - Dark data auditing across enterprise drives and SharePoint.

## 🚀 Local Development

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation

```bash
# Clone the repository
git clone https://github.com/haidershabbir678/lis-advisory.git

# Navigate into project directory
cd lis-advisory

# Install dependencies
npm install

# Start local development server
npm run dev
```

Server will be running at `http://127.0.0.1:5173/`

### Production Build

```bash
npm run build
npm run preview
```
